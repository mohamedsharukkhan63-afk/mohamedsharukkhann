WARM PARALLAX PORTFOLIO
=======================
Files:
- index.html : portfolio content and structure
- style.css  : responsive styling, warm palette, parallax and reveal effects
- script.js  : scroll effects, reveal animations, mobile navigation, current year
- WhatsApp Image 2026-10-26 at 18.02.57.jpeg : sunset illustration used in the hero
- Sunset Coastal Vista with Boy and Cat.png : sunset illustration used in the skills section
- OIG1.webp : sunset coastal illustration used in the Contact section
- OIG1 (2).webp : SmallBizStudio project thumbnail
- OIG1 (1).webp : FitQuest project thumbnail
- OIG4.eUOG.webp : Valinokkam project thumbnail

RUN LOCALLY:
1. Extract this folder.
2. Open index.html in a browser, or open the folder in VS Code.
3. Optional: use the Live Server extension in VS Code and click "Go Live".

EDIT YOUR DETAILS:
- Update About and project descriptions in index.html.
- Replace project links and social links with your preferred destinations.
- Colors are defined as CSS variables near the top of style.css.

Note: Google Fonts requires an internet connection; the site falls back to system fonts.
